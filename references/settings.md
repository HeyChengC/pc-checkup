# 设置建议：让 C 盘不再反复爆满，让电脑用起来更顺

用户问了才给。从报告的 `facts` 和清单里的大户出发，挑三到五条最相关的，不要整份念。

原则：

- 只给建议。用户逐条同意才改，一次改一条，改之前说清楚怎么改回去。
- 不让用户下载或安装任何东西。
- 需要管理员权限的，告诉用户要弹一次授权窗口。
- 不建议做的事放在最后，用户问到时照实说。

## 一、让缓存不再堆到 C 盘（治本）

C 盘清完又满，是因为 AI 工具默认把模型和缓存写在用户目录下。把位置改到空间大的盘，以后就不往 C 盘堆了。

做法是设置用户环境变量（不需要管理员，新开的程序才生效），改回去就是删掉这个变量：

```
setx HF_HOME "D:\ai-cache\huggingface"
```

| 报告里看到什么 | 建议设置的变量 | 管的是什么 |
|---|---|---|
| HuggingFace 模型在 C 盘且 `facts.env_HF_HOME` 为空 | `HF_HOME` | HuggingFace 模型和数据集 |
| PyTorch hub 模型在 C 盘 | `TORCH_HOME` | torch.hub 下载的权重 |
| ModelScope 模型在 C 盘 | `MODELSCOPE_CACHE` | ModelScope 模型 |
| Ollama 模型在 C 盘 | `OLLAMA_MODELS` | Ollama 模型（改完要重启 Ollama） |
| Playwright 浏览器在 C 盘 | `PLAYWRIGHT_BROWSERS_PATH` | Playwright 下载的浏览器 |
| pip 缓存大 | `PIP_CACHE_DIR` | pip 下载缓存 |
| uv 缓存大 | `UV_CACHE_DIR` | uv 下载缓存（和项目放同一个盘时还能省空间） |
| npm 缓存大 | 运行 `npm config set cache "D:\ai-cache\npm"` | npm 下载缓存 |

要点：

- 设置变量只管以后新下载的。已经在 C 盘的旧缓存，要么在清单里清掉让它重新下载到新位置，要么由用户自己把文件夹整个挪过去。
- 目标盘要是本机的固定硬盘。移动硬盘拔掉以后工具会报错。
- 一个变量设完，让用户新开一个终端跑一次相关工具，确认它往新位置写了，再设下一个。

## 二、项目习惯（不用改系统）

- 视频项目、渲染输出、素材放在非系统盘。
- 每个项目的中间产物（帧序列、临时配音、抽帧）放进固定名字的文件夹，比如 `_tmp`。交付后整个删掉，体检时也好认。
- 成片导出并确认后，帧序列就可以清了。
- 不再维护的项目，`node_modules` 和虚拟环境可以清，要用时再装。

## 三、系统设置

| 报告里看到什么 | 建议 | 代价和改回去的办法 |
|---|---|---|
| `notTouched.system` 里有休眠文件，几个 GB 以上，且用户从不用"休眠" | 关闭休眠：管理员运行 `powercfg /hibernate off`，释放和内存差不多大的空间 | "休眠"和"快速启动"没有了，开机慢几秒。`powercfg /hibernate on` 改回 |
| `facts.longPathsEnabled` 为假 | 开启长路径，避免 node_modules、模型缓存因为路径超过 260 个字符报错。需要管理员，改注册表 `HKLM\SYSTEM\CurrentControlSet\Control\FileSystem` 的 `LongPathsEnabled` 为 1 | 没有副作用，改回 0 即可 |
| `facts.gpuHardwareScheduling` 为假且有独立显卡 | 设置 > 系统 > 屏幕 > 显示卡 > 更改默认图形设置，打开"硬件加速 GPU 计划"，重启生效 | 个别旧驱动上会不稳定，关掉即恢复 |
| `facts.powerPlan` 是"节能" | 渲染时插电，电源模式选"最佳性能"或"平衡" | 笔记本更费电、风扇更响 |
| `facts.startupEntries` 很多 | 把名单列给用户，由用户在任务管理器的"启动应用"里关掉用不到的 | 关掉的软件不再开机自启，随时可以重新打开 |
| `facts.ramFreeBytes` 长期很低 | 渲染、抠像、跑模型时，关掉不用的浏览器标签和后台软件；重任务一个一个跑 | 无 |
| 微信等聊天数据在 C 盘且很大 | 在软件自己的设置里把文件存储位置改到别的盘 | 由软件自己迁移，照它的提示做 |

## 四、不建议做的

用户问到时说明原因，不要帮着做：

- 注册表清理、"内存清理"、加速球：收益几乎为零，有删错的风险。
- 关闭页面文件：内存不够时程序直接崩溃，渲染和跑模型最容易中招。
- 关闭 Windows Defender、Windows 更新、搜索索引等系统服务：换来的速度很有限，风险和麻烦更大。
- 给固态硬盘做碎片整理：没有用，还增加磨损。系统自带的"优化驱动器"对固态硬盘做的是 TRIM，保持默认即可。
- 手动删除 `C:\Windows\Installer`、`WinSxS`：会导致软件无法卸载和修复、系统更新失败。
